# 피자집브레이크타임 Monthly Picks 제품 요구사항

## 1. 제품 목적

밴드 `피자집브레이크타임` 멤버들이 매달 연주할 곡을 제안하고, 모든 참여자의 의사를 확인해 합주곡을 선정한다.

## 2. 대상 사용자

- 밴드 멤버: 관리자 초대 후 PIN 설정, 곡 등록, 본인 곡 수정·삭제, 투표
- 최고 관리자(`OWNER`): 모든 운영 기능과 관리자 지정·해제
- 부관리자(`ADMIN`): 참여자와 월별 투표를 관리하는 일상 운영 기능

## 3. 월별 진행 단계

1. **곡 등록 중**: 관리자가 참여자 명단을 구성하고, 참여자가 곡을 등록하거나 본인 곡을 수정·삭제한다.
2. **투표 중**: 신규 곡 등록과 곡 수정을 막고 좋아요 또는 싫어요를 받는다.
3. **마감**: 투표를 잠그고 선정 결과를 표시한다.

단계 전환은 관리자가 수행한다. `곡 등록 중 ↔ 투표 중 → 마감` 흐름을 사용하며 자동 마감은 이후 기능으로 고려한다.

- 투표 시작 후 참여자 명단은 변경할 수 없다.
- 참여자 변경이 필요하면 등록 단계로 되돌린 뒤 변경한다.
- 투표 단계에서 등록 단계로 되돌리면 기존 투표를 모두 삭제하고 다시 투표받는다.
- 되돌리기 전에는 투표 초기화를 알리는 확인 절차가 필요하다.
- 마감 이후에는 곡, 투표, 참여자와 결과를 수정하거나 이전 단계로 되돌릴 수 없다.
- 잘못 마감한 경우 기존 월을 무효 처리하고 새 투표방을 복제해 다시 진행한다.

## 4. 핵심 기능

### 곡 등록

필수 입력값:

- 밴드명 또는 아티스트명
- 곡 제목
- 곡 구분(남성곡 또는 여성곡)
- 등록자 이름 또는 별명
- 개인 PIN

선택 입력값:

- YouTube 또는 음원 링크
- 간단한 메모

### 곡 수정과 삭제

- 등록할 때 입력한 이름과 PIN을 다시 확인한다.
- 본인이 등록한 곡만 수정하거나 삭제할 수 있다.
- 투표 단계가 시작된 뒤에는 일반 사용자가 곡을 수정하거나 삭제할 수 없다.

### 투표

- 각 참여자는 곡마다 `좋아요`, `싫어요`, `미투표` 중 하나의 상태를 가진다.
- 같은 참여자는 같은 곡에 한 번만 투표할 수 있으며 선택을 변경할 수 있다.
- 이번 달 참여자 전원이 좋아요를 선택한 곡을 선정 후보로 표시한다.
- 미투표자는 전원 동의에 포함되지 않은 것으로 처리한다.
- 기본 운영 기준은 참여자 7명이 매달 최소 2곡씩 추천하는 것이며, 화면에서 개인별 제출 현황을 확인할 수 있다.
- 멤버 목록에는 각 멤버의 등록 곡 수와 현재 단계에 따른 `등록 완료/등록 중` 또는 `투표 완료/미투표` 상태를 표시한다.
- 사이드 현황 카드는 등록 단계에서 2곡 제출 완료 인원을, 투표 단계에서 투표 완료 인원과 전원 동의 후보 수를 표시한다.
- 후보가 14곡 이상이어도 비교하기 쉽도록 전체, 남성곡, 여성곡, 내가 올린 곡 필터를 제공한다.
- 투표 단계에서는 좋아요가 많은 순서, 전원 투표 완료, 전원 동의 필터를 추가로 제공한다.
- 현재 가장 많은 좋아요를 받은 곡에는 `인기곡` 배지를 표시하며, 동률인 곡은 모두 표시한다.

### 월별 기록

- 매달 별도의 곡 목록, 참여자, 투표 기간과 결과를 가진다.
- 지난달 선정곡을 조회할 수 있어야 한다.
- 관리자는 월별 메인 문구와 설명을 작성하거나 수정할 수 있다.

## 5. 사용자 식별 방식

- 정식 계정이나 소셜 로그인은 사용하지 않는다.
- 관리자가 미리 등록한 사람만 참여할 수 있으며, 명단에 없는 방문자는 곡 등록과 투표를 할 수 없다.
- 관리자가 참여자를 추가하면 한 번만 사용할 수 있는 초대 코드 또는 초대 링크를 발급한다.
- 참여자는 이름과 초대 코드를 확인한 뒤 최초 PIN을 설정한다. PIN 설정 후 초대 코드는 즉시 만료된다.
- 이후 사용자는 `이름 또는 별명 + PIN`으로 본인을 확인한다.
- 각 참여자는 보컬, 기타, 베이스, 드럼, 키보드 중 하나를 주 포지션으로 가지며 관리자가 멤버 관리 화면에서 변경한다.
- 별도의 개인 프로필 화면과 프로필 사진, 소개글, SNS 기능은 만들지 않는다.
- PIN을 잊으면 관리자가 원래 PIN을 확인하는 대신 새 초기화 코드를 발급한다.
- PIN 확인에 성공하면 제한된 시간 동안 사용할 수 있는 세션을 발급한다.
- 이름과 PIN으로 사용자를 명확히 식별하기 위해 정규화한 이름의 중복을 허용하지 않는다.
- PIN은 원문으로 저장하지 않고 안전하게 해시한다.
- PIN은 6자리 이상을 기본으로 안내한다.
- 반복된 PIN 실패는 사용자 이름과 요청 출처를 기준으로 일정 시간 제한한다.

## 6. 관리자 기능

- 관리자는 일반 사용자 PIN 외에 12자 이상의 개별 관리자 암호를 사용한다.
- 관리자 암호는 서로 공유하지 않으며 안전하게 해시해 저장한다.
- 관리자 확인 후 유효기간이 있는 관리자 세션을 발급한다.
- 마감, 참여자 제외, PIN 초기화, 관리자 지정 같은 중요한 작업은 관리자 암호를 다시 확인한다.

### 최고 관리자 `OWNER`

- 월별 투표방 생성 및 관리
- 월별 메인 문구와 설명 관리
- 참여자 추가·제외와 초대 코드 발급
- 단계 전환, 투표 초기화, 마감과 결과 확정
- 참여자 PIN 초기화
- 부관리자 지정 및 해제
- 최고 관리자 권한 이전
- 운영 기록 조회

### 부관리자 `ADMIN`

- 월별 투표방 생성 및 관리
- 월별 메인 문구와 설명 관리
- 참여자 추가·제외와 초대 코드 발급
- 단계 전환, 투표 초기화, 마감과 결과 확정
- 참여자 PIN 초기화
- 문제가 있는 곡 숨김 또는 삭제
- 운영 기록 조회

부관리자는 다른 관리자를 추가·삭제하거나 최고 관리자 권한을 이전하거나 전체 데이터를 삭제할 수 없다.

## 7. 선정 규칙

현재 합의된 기본 규칙:

- 해당 월의 참여자 전원이 좋아요를 누르면 선정 후보가 된다.
- 한 명이라도 싫어요 또는 미투표 상태이면 전원 동의가 아니다.

구현 전에 결정할 항목:

- 만장일치 곡이 여러 개일 때 최종 한 곡을 고르는 방법
- 마감일까지 만장일치 곡이 없을 때 처리 방법
- 중도 합류 또는 탈퇴한 참여자의 투표 반영 방법
- 투표 결과를 마감 전 공개할지 여부

## 8. 이번 버전에서 하지 않는 것

- 소셜 로그인
- 공개 커뮤니티 기능
- 음원 파일 직접 업로드
- 결제 기능
- 여러 밴드를 하나의 계정으로 관리하는 기능

## 9. 완료 기준

최초 사용 가능한 버전은 다음 흐름이 실제 데이터로 동작해야 한다.

1. 관리자가 월과 참여자 명단을 만든다.
2. 관리자가 참여자에게 일회용 초대 코드를 발급한다.
3. 참여자가 초대 코드로 본인을 확인하고 PIN을 설정한다.
4. 참여자가 이름과 PIN으로 곡을 등록한다.
5. 등록자가 본인 곡을 수정하거나 삭제한다.
6. 관리자가 참여자 명단을 고정하고 투표를 시작한다.
7. 참여자들이 좋아요 또는 싫어요를 선택한다.
8. 시스템이 전원 동의 여부를 계산한다.
9. 관리자가 마감하고 변경 불가능한 결과를 과거 기록으로 남긴다.
